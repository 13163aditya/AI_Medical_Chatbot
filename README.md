📖 About The Project
This project is a Streamlit web application that serves as an AI-powered medical assistant. Instead of relying on generalized knowledge from a large language model, it answers questions based on a specific, pre-processed set of medical documents. This is achieved by creating a vector database from the source documents and retrieving relevant information to construct a precise and reliable answer.
The chatbot is designed to be a helpful informational tool, not a substitute for professional medical advice.
